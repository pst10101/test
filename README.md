# 교실 혼잡도 사이트

교실마다 둔 태블릿이 카메라로 사람 수를 세고, 방문자는 폰으로 어느 교실이 붐비는지 봐요.
서버 없이 파일만으로 돌아가서 GitHub Pages나 Cloudflare 어디에 올려도 돼요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | **방문자 화면.** 층별 지도, 목록, 지금 한산한 곳. 복도에 세워 둔 탭에 띄우는 화면 |
| `board.html` | **전자칠판 화면.** 가로 한 화면에 모든 층과 지금 한산한 곳, 멀리서도 보이는 큰 글씨 |
| `counter.html` | **교실 태블릿 화면.** `counter.html?room=2-3`처럼 반마다 주소가 달라요 |
| `admin.html` | **담당자 화면.** 태블릿 상태·배터리, 혼잡도 직접 설정, 프로그램 정보 수정 |
| `check.html` | 장비 점검 페이지 (전에 쓴 테스트 페이지) |
| `config.js` | **설정 파일. 이것만 고치면 돼요.** 교실 목록, Firebase 설정 |
| `common.js`, `style.css` | 공통 코드와 디자인 (안 고쳐도 돼요) |

Firebase 설정을 비워 두면 **예시 모드**로 돌아가요. 가짜 데이터로 화면을 미리 볼 수 있어요.

## 1. Firebase 준비 (10분)

> **이 사이트는 이미 끝났어요.** 프로젝트 `bhhsftv26`, 설정값은 `config.js`에 들어 있고,
> 담당자 계정은 `bhhsfv26@gmail.com`, 보안 규칙도 그 계정 기준으로 적용돼 있어요.
> 아래는 새 프로젝트를 처음부터 만들 때를 위한 설명이에요.

1. https://console.firebase.google.com 에 구글 계정으로 들어가서 **프로젝트 만들기**. 이름은 아무거나, Google 애널리틱스는 꺼도 돼요.
2. 프로젝트 첫 화면에서 **웹 앱 추가**(`</>` 모양) → 앱 이름 적고 **앱 등록**.
   화면에 나오는 `firebaseConfig`에서 `apiKey`, `authDomain`, `projectId`, `appId` 네 값을 `config.js`의 `firebase` 칸에 붙여 넣어요.
   (이 값들은 공개돼도 괜찮아요. 보안은 아래 규칙이 지켜요.)
3. 왼쪽 메뉴 **Authentication** → 시작하기 → **로그인 방법**에서 **이메일/비밀번호** 사용 설정.
   **사용자** 탭 → **사용자 추가**로 담당자 계정을 하나 만들어요. 태블릿 13대와 관리 화면 모두 이 계정으로 로그인해요.
4. 왼쪽 메뉴 **Firestore Database** → 데이터베이스 만들기 → 위치는 `asia-northeast3 (서울)` → **프로덕션 모드**로 만들기.
5. Firestore의 **규칙** 탭에 아래 내용을 붙여 넣고, `담당자@이메일.com`을 3번에서 만든 이메일로 바꾼 뒤 **게시**.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isStaff() {
      return request.auth != null
        && request.auth.token.email in ["담당자@이메일.com"];
    }

    // 혼잡도와 프로그램 정보: 누구나 읽고, 담당자만 바꿈
    match /status/{room} {
      allow read: if true;
      allow write: if isStaff();
    }
    match /rooms/{room} {
      allow read: if true;
      allow write: if isStaff();
    }

    // 태블릿 상태(배터리 등): 담당자만
    match /devices/{room} {
      allow read, write: if isStaff();
    }
  }
}
```

담당자 계정을 여러 개 쓰려면 `["a@gmail.com", "b@gmail.com"]`처럼 쉼표로 이어 적으면 돼요.

### 계정 두 개, 역할이 달라요

| 계정 | 정체 | 쓰는 곳 |
|---|---|---|
| Firebase 콘솔에 로그인한 **구글 계정** | 프로젝트 **주인(관리자)** | Firebase 콘솔에서 데이터베이스·보안 규칙·담당자 계정을 만들고 지울 때만. 사이트에서는 안 써요 |
| `bhhsfv26@gmail.com` | **사이트 로그인 전용** 계정 (Firebase 안에만 있음, 구글 계정 아님) | 교실 탭(`counter.html`)과 관리 화면(`admin.html`) 로그인, 탭 멈춤 버튼 잠금 해제 |

- 담당자 계정 주소는 실제로 없는 지메일이에요. 로그인은 문제없지만 **비밀번호를 잊으면 재설정 메일로 찾을 수 없으니** 따로 적어 두세요.
- 담당자 비밀번호가 퍼져도 혼잡도 값을 바꾸는 정도까지만 돼요. 프로젝트 자체는 구글 계정 주인만 건드릴 수 있어요.
- **구글 계정 비밀번호는 아무에게도 알려주지 마세요.** 선생님도 콘솔을 봐야 하면 Firebase 프로젝트 설정 → **사용자 및 권한**에서 선생님 구글 계정을 따로 추가하세요.
- 담당자 계정을 바꾸려면 Authentication → Users에서 새로 만들고, Firestore **규칙**의 이메일도 같이 바꿔야 해요.
- 축제가 끝나면 Authentication에서 담당자 계정을 지우거나, 프로젝트를 통째로 삭제하면 깔끔해요.

## 2. 교실 목록 고치기

`config.js`의 `rooms`에 지금은 예시 13개 반이 들어 있어요. 실제 반, 층, 프로그램으로 바꿔 주세요.
목록 순서가 지도에서 복도를 따라 놓이는 순서예요.

프로그램 이름, 소개, 운영 시간, 혼잡 기준 인원은 나중에 **관리 화면에서도 고칠 수 있어요.**
교실을 새로 추가하거나 빼는 것, 층을 바꾸는 것은 `config.js`에서 해요.

## 3. 올리기

### GitHub Pages
저장소에서 **Add file → Upload files** → 파일 7개를 한꺼번에 끌어다 놓고 **Commit changes**.
전에 올린 점검용 `index.html`은 새 파일로 덮어써지고, 점검 페이지는 `check.html`로 남아요.

### Cloudflare 도메인을 쓰려면 (둘 중 하나)

**A. GitHub Pages에 내 도메인 연결**
1. Cloudflare → 내 도메인 → **DNS** → 레코드 추가: 유형 `CNAME`, 이름 `crowd`(원하는 이름), 대상 `pst10101.github.io`.
   처음에는 프록시 상태를 **DNS 전용**(회색 구름)으로 두는 게 인증서 발급이 잘 돼요.
2. GitHub 저장소 **Settings → Pages → Custom domain**에 `crowd.내도메인.com` 입력 → Save.
   몇 분 뒤 인증서가 준비되면 **Enforce HTTPS**를 체크해요.

**B. Cloudflare Pages에 직접 올리기**
Cloudflare → **Workers & Pages** → 만들기 → **Pages** → 직접 업로드 → 이 폴더를 올리고 배포 → **사용자 지정 도메인**에서 내 도메인 연결.

어느 쪽이든 마지막으로 Firebase **Authentication → 설정 → 승인된 도메인**에 새 도메인을 추가해 주세요.

## 4. 행사 당일

1. **관리 화면**(`admin.html`)을 열고 로그인 → 아래 **교실 태블릿 주소**에서 반별 주소를 복사해요.
2. 각 교실 탭 크롬에서 그 주소를 열고 로그인 → **카운트 시작** → 카메라 허용.
   탭은 교실 뒤쪽 높은 곳에, 충전기를 꽂아서 두세요. 주소를 즐겨찾기에 넣어 두면 다음엔 바로 열려요.
   - **자동 시작:** 한 번 설정한 탭은 주소만 열면 5초 뒤 알아서 카운트를 시작해요. 탭이 재부팅돼도 주소만 다시 열면 돼요.
   - **버튼 잠금:** 카운트 중에는 **담당자 메뉴**에 담당자 비밀번호를 넣어야 1분 동안 멈춤·카메라 전환을 쓸 수 있어요. 방문자가 눌러도 멈추지 않아요.
   - 담당자가 **멈춤**을 누른 탭은 다시 열어도 자동 시작하지 않아요. **카운트 시작**을 눌러야 해요.
   - 안드로이드 **앱 고정(화면 고정)**을 켜 두면 방문자가 크롬을 닫거나 다른 앱으로 못 나가요.
3. **전자칠판**의 브라우저(크롬 권장)에서 `board.html`을 열고 오른쪽 아래 **전체 화면**을 눌러요.
   스크롤 없이 한 화면에 다 나오고, 마우스를 안 움직이면 커서와 버튼이 숨어요. 연결이 끊기면 스스로 다시 연결하고, 3시간마다 새로고침해요.
   어두운 화면이 보기 편하면 `board.html?theme=dark`로 열면 돼요.
4. **방문자 화면**(사이트 첫 주소)은 남는 탭이 있으면 복도에 세워 두고 띄우면 돼요. 교실을 누르면 소개와 운영 시간이 나와요.
5. 관리 화면에서 꺼진 태블릿, 배터리 부족을 확인해요. 카메라가 이상하면 **직접 설정**으로 여유/보통/혼잡을 고정할 수 있어요. 다시 **자동**을 누르면 카메라 값으로 돌아가요.

## 알아 둘 것

- **개인정보:** 영상은 태블릿 안에서만 분석하고, 서버로는 사람 수와 단계만 보내요. 교실 앞에 안내문을 붙여 주세요.
- **무료 사용량:** Firestore 무료 한도는 하루 쓰기 2만 회, 읽기 5만 회예요.
  태블릿은 단계가 바뀔 때와 5분마다만 방문자 화면을 갱신하고, 방문자 화면은 1분 넘게 안 보고 있으면 연결을 끊어서 보통 축제 규모면 충분해요.
  방문자가 아주 많으면 `config.js`의 `refreshMin`을 10으로 늘리면 읽기가 줄어요.
- **정보 없음:** 태블릿에서 12분 넘게 소식이 없으면 방문자 화면에 회색 '정보 없음'으로 바뀌어요.
- **인식 기준:** 사람을 너무 적게 세면 `config.js`의 `minScore`를 0.4로 낮춰 보세요.
